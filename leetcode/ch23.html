专题 23动态规划高阶：区间、树形与状态压缩

专题 09 你建立了 DP 的「五步法」：定义状态、找转移、定边界、填表、取答案，并用它解决了一大批一维问题（斐波那契、打家劫舍、爬楼梯）。 这一章我们承认一个事实：进阶 DP 并没有发明新思维，只是把「状态」变得更高维——状态不再只是「前 i 个」，而是「区间的两端」「树上的节点」「一个二进制集合」。 你会在本章遇到区间 DP（最长回文子序列、戳气球）、树形 DP（打家劫舍 III）、状态压缩 DP（优美的排列），以及把递归写舒服的「记忆化搜索」。承接 专题 09 和 专题 10 的五步法，本章是 DP 从「能写」到「写得出复杂题」的关键一跃。

学习目标
掌握区间/树形/状压三类高阶 DP
前置要求
专题 09/10 五步法、专题 14 位运算、专题 20 并查集思维
本章产出

23.1进阶 DP 只是把状态定义变复杂

先打消畏难情绪。无论状态多花哨，五步法的骨架一字未改：

进阶形态状态维度怎么变例子
区间 DP状态是「区间两端」dp[i][j]最长回文子序列、戳气球
树形 DP状态挂在「树上节点」，常返回多个值打家劫舍 III
状态压缩状态是「二进制集合」dp[mask]优美的排列
记忆化搜索写法换「自顶向下递归 + 缓存」矩阵最长递增路径

一个统一的心法

不管维度怎么升，问自己的永远是两句老话：「dp 数组的每个格子代表什么？」「这个格子的值，能由哪些更小的格子推出来？」 区间 DP 里「更小」是「更短的区间」，树形 DP 里「更小」是「更浅的子树」，状压里「更小」是「更少元素的集合」。抓住这条线，三类都能拆。

本章与前面的承接：区间 DP 的 dp[i][j] 转移，和 21.2 节「最长回文子串」的 DP 版本是同一套思想；树形 DP 是把 专题 09 的「线性打家劫舍」从数组搬到了树上；状压要用到 专题 14 的位运算技巧。

23.2最长回文子序列：区间 DP（中等，力扣 516）

中等 核心：dp[i][j] + 遍历方向

题意：给定字符串 s，求它的最长回文子序列的长度（子序列 = 可以删字符、不要求连续）。例：s = "bbbab" → 最长回文子序列是 "bbbb"（取第 1、2、3、5 个字符），长度 4。

思路推导

第一步，明确「子序列」和「子串」的天壤之别。21.2 节的最长回文子串要求连续，用中心扩展 O(1) 空间就搞定。但子序列不连续，中心扩展彻底失效——你得决定「跳过哪些字符」。这正是区间 DP 的舞台。

第二步，定义状态。令 dp[i][j] = 子串 s[i..j] 中最长回文子序列的长度。答案就是 dp[0][n-1]。

第三步，转移方程——看两端字符。对区间 [i, j]：

  • 若 s[i] == s[j]：这两个字符可以同时作为回文的两端，于是 dp[i][j] = dp[i+1][j-1] + 2（中间那段的最长，加这一对）；
  • 若 s[i] != s[j]：至少得丢掉一端，取「丢左」和「丢右」的较大者：dp[i][j] = max(dp[i+1][j], dp[i][j-1])。

第四步，遍历顺序为什么 i 从后往前。注意转移依赖 dp[i+1][...] 和 dp[i][j-1]——也就是左下方和正下方的格子。所以必须保证「算 dp[i][j] 时，它左下/下方的格子已经算好」。做法：i 从 n-1 倒着往 0 走，j 从 i+1 顺着往 n-1 走（j 永远大于 i，区间长度从小变大）。这样每个 dp[i][j] 依赖的更短区间都先填完。边界：i == j 时 dp[i][i] = 1（单字符本身是回文）。

参考代码

class Solution {
    public int longestPalindromeSubseq(String s) {
        int n = s.length();
        int[][] dp = new int[n][n];
        // 单字符区间：长度 1 的回文子序列长度为 1
        for (int i = 0; i < n; i++) dp[i][i] = 1;

        // i 从后往前，j 从 i+1 往后；保证依赖的更短区间先算
        for (int i = n - 1; i >= 0; i--) {
            for (int j = i + 1; j < n; j++) {
                if (s.charAt(i) == s.charAt(j)) {
                    dp[i][j] = dp[i + 1][j - 1] + 2;   // 两端相同，包起来
                } else {
                    dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]); // 丢一端
                }
            }
        }
        return dp[0][n - 1];                    // 整串的最长回文子序列
    }
}

复杂度

O(n²) 时间（两重循环），O(n²) 空间（二维表）。对比中心扩展求子串是 O(n²) 时间 O(1) 空间——但子序列问题中心扩展干不了，DP 是标准解。

与 21.2 节对比（必会）：子串「连续」→ 中心扩展（O(1) 空间）；子序列「可跳」→ 区间 DP（O(n²) 空间）。两者都叫「回文」，但一个是物理连续、一个是逻辑挑选，解法截然不同。面试若问「最长回文」务必先确认是子串还是子序列！

巩固练习（先自己想 15 分钟，卡住再看括号里的提示）

  • 最长回文子串（力扣 5，中等）——对比题，连续版；差异在必须连续，故用中心扩展而非 DP（提示：专题 21.2 的 expand 即可，O(1) 空间）。
  • 让字符串成为回文串的最少插入次数（力扣 1312，困难）——同区间 DP；差异在求最少插几个字符使其变回文（提示：dp[i][j] 表示最少插入数，s[i]==s[j] 则 =dp[i+1][j-1]，否则 =min(dp[i+1][j],dp[i][j-1])+1；答案 = 总长 - 最长回文子序列长）。
  • 最长公共子序列（力扣 1143，中等）——区间 DP 的孪生；差异在两个不同串（提示：dp[i][j] 为 s1[0..i] 与 s2[0..j] 的 LCS，相等 +1 否则取 max，是子序列 DP 的基本功）。

23.3戳气球：区间 DP（困难，力扣 312，选学）

困难 核心：反向思维 + 开区间 选学

题意：有 n 个气球排成一排，第 i 个分值 nums[i]。戳破气球 i 时，获得 nums[left] * nums[i] * nums[right] 分（left, right 是它此时左右相邻的气球）。戳完所有气球求最大总分。例：nums = [3,1,5,8] → 最大 167。

思路推导

第一步，正向想为什么难。「先戳哪个」会影响后续相邻关系，状态互相缠绕，正向 DP 极难定义——戳破一个，数组就变了。

第二步，反向思维——「最后戳哪个」。换个角度：与其想「先戳谁」，不如想「最后被戳的是谁」。在最后一步，[i, j] 区间内只剩一个气球 k 没戳，它的左右边界是「区间外的 i-1 和 j+1」（这两个此时已经固定、不再变）。所以戳 k 得分 nums[i-1]*nums[k]*nums[j+1]。那么 [i, j] 的最大得分 = 左半 [i, k-1] 的最大 + 右半 [k+1, j] 的最大 + 这一步得分。

第三步，开区间 dp[i][j]。定义 dp[i][j] = 戳破开区间 (i, j) 内所有气球（不含 i、j 本身）能获得的最大分数。这里 i、j 是「虚拟边界」，永远不会被戳，只作为乘数存在。为处理首尾，在 nums 首尾各补一个 1（如 [1,3,1,5,8,1]），让任何区间都有合法左右邻居。

第四步，转移：dp[i][j] = max over k∈(i,j) of (dp[i][k] + dp[k][j] + nums[i]*nums[k]*nums[j])。遍历顺序同样是 i 从后往前、j 从 i+1 往后（依赖更短开区间）。

参考代码（选学，看懂思想即可）

class Solution {
    public int maxCoins(int[] nums) {
        int n = nums.length;
        int[] a = new int[n + 2];            // 首尾补 1
        a[0] = 1; a[n + 1] = 1;
        for (int i = 0; i < n; i++) a[i + 1] = nums[i];

        int[][] dp = new int[n + 2][n + 2];  // dp[i][j]: 开区间(i,j)最大分
        // i 从后往前，j 从 i+1 往后，区间长度逐渐增大
        for (int i = n; i >= 1; i--) {
            for (int j = i + 1; j <= n + 1; j++) {
                for (int k = i + 1; k < j; k++) {   // 最后戳 k
                    int gain = a[i] * a[k] * a[j];   // 此时左右邻居是 i 和 j
                    dp[i][j] = Math.max(dp[i][j],
                                        dp[i][k] + dp[k][j] + gain);
                }
            }
        }
        return dp[0][n + 1];                  // 开区间(0, n+1)即全部
    }
}

复杂度

O(n³) 时间（三重重循环），O(n²) 空间。第一次学可跳过；它展示的「反向定义最后一步」是区间 DP 的高级套路。

选学提示：「最后戳哪个」的反向建模非常反直觉，但它是处理「操作会改变结构」类问题的通用钥匙（合并石头、多边形三角剖分同理）。不必默写，理解「开区间 + 虚拟边界 + 反着定义」三件套即可。

巩固练习（先自己想 15 分钟，卡住再看括号里的提示）

  • 合并石头的最低成本（力扣 1000，困难）——同「最后合并哪堆」的反向区间 DP；差异在每次合并相邻 K 堆（提示：dp[i][j][k] 表示 [i,j] 合并为 k 堆的最小代价，最后一步把两堆合成一堆）。
  • 移除盒子（力扣 546，困难）——区间 DP + 额外维度；差异在相同颜色的盒子连续移除有加成（提示：dp[i][j][k] 表示 [i,j] 且右侧已连着 k 个同色盒子的最大分，转移考虑是否把同色段一起消）。
  • 多边形三角剖分的最低得分（力扣 1039，中等）——同反向区间 DP；差异在选顶点 k 把多边形切成三角形（提示：dp[i][j] 表示顶点 i..j 构成多边形的最小得分，最后一条边连 i-j，枚举顶点 k 形成三角形 i,k,j）。

23.4打家劫舍 III：树形 DP（中等，力扣 337）

中等 核心：每个节点返回「偷/不偷」两值

题意：房子排成二叉树结构，不能偷直接相连的两户（父子不能同时偷）。求能偷到的最大金额。例：[3,2,3,null,3,null,1] → 偷根 3 + 右孙 3 + 右右孙 1 = 7，返回 7。

思路推导

第一步，承接到线性版。专题 09 的打家劫舍是在数组上：dp[i] 表示「前 i 户最大」，转移 dp[i]=max(偷i+不偷i-1, 不偷i=dp[i-1])。现在结构从「数组」变成「树」，思路完全类比，只是遍历方式换成了后序遍历。

第二步，每个节点返回两个值。对任一节点，我们必须知道「偷它」和「不偷它」两种情况各自的最大收益，因为父节点需要根据子节点的这两种值做决定。所以设计：递归返回 int[2]，[0] = 不偷当前节点的最大收益，[1] = 偷当前节点的最大收益。

第三步，转移（后序）。先递归算左右子树各自的 [偷, 不偷]，再组合：

  • 偷当前节点：则左右孩子都不能偷 → val + left[0] + right[0]；
  • 不偷当前节点：左右孩子偷不偷都行，各取 max → max(left[0],left[1]) + max(right[0],right[1])。

后序遍历保证「先算出孩子、再算自己」，天然契合「子问题优先」。

参考代码

class Solution {
    public int rob(TreeNode root) {
        int[] res = dfs(root);
        return Math.max(res[0], res[1]);     // 根偷或不偷取大
    }

    // 返回 int[2]： [0]=不偷当前节点的最大收益, [1]=偷当前节点的最大收益
    private int[] dfs(TreeNode node) {
        if (node == null) return new int[]{0, 0};   // 空节点两值皆 0
        int[] left = dfs(node.left);       // 后序：先递归左右子树
        int[] right = dfs(node.right);

        int robHere = node.val + left[0] + right[0];        // 偷：孩子都不能偷
        int skipHere = Math.max(left[0], left[1])
                      + Math.max(right[0], right[1]);       // 不偷：孩子取各自最大
        return new int[]{skipHere, robHere};
    }
}

复杂度

O(n) 时间（每个节点访问一次），O(h) 空间（递归栈，h 为树高）。把「数组 DP」原封不动地翻译成「树上后序 + 返回双值」即可。

边界自查：① 单节点 → 偷它得 val。② 只有根和左孩子 → 根与左互斥，取大。③ 空树 → 返回 0。核心是别忘了返回数组的两个元素都要算，否则父节点拿不到正确信息（见 23.7 节坑二）。

巩固练习（先自己想 15 分钟，卡住再看括号里的提示）

  • 二叉树中的最大路径和（力扣 124，困难）——同后序返回双值（实际返回「向上贡献」）；差异在路径可拐弯、不经过根（提示：返回「含当前节点向上延伸的最大贡献」，同时在递归中更新「经过当前节点的全局最大 = 左贡献 + 右贡献 + 值」）。
  • 最长同值路径（力扣 687，中等）——树形 DP 返回「同值链长」；差异在只在值相等时才能接上（提示：返回以当前节点为端点的最长同值链，值不等则链断为 0，全局答案取左右链之和）。
  • 二叉树的直径（力扣 543，简单）——后序返回深度；差异在答案是左右深度之和而非累加值（提示：返回节点最大深度，更新全局直径 = 左深 + 右深）。

23.5优美的排列：状态压缩 DP（中等，力扣 526）

中等 核心：bitmask 表示已选集合

题意：给定 n，构造一个 1~n 的排列 nums，要求对每个位置 i（1-indexed），nums[i] 能被 i 整除，或 i 能被 nums[i] 整除。求满足条件的排列个数。例：n=2 → [1,2] 和 [2,1] 都满足，返回 2。

思路推导

第一步，为什么必须状压。暴力枚举所有排列是 n! 种——n=15 时 15! ≈ 1.3×10¹²，直接爆。但注意到 n≤15，而「哪些数字已经被选」只有 2ⁿ 种状态（2¹⁵=32768），完全可枚举。用二进制位表示「已选集合」，把指数级的排列压成多项式级的子集，这就是状态压缩 DP。

第二步，定义状态。设 dp[mask] = 用掉 mask 所表示的数字集合后，能形成的合法排列个数。其中 mask 的第 k 位为 1 表示数字 k+1 已被选（位运算技巧见 专题 14）。

第三步，转移——一位一位填。当前已选集合 mask，意味着已经填好了前 cnt 个位置（cnt = mask 中 1 的个数，即 Integer.bitCount(mask)）。下一个要填的是第 cnt+1 个位置。枚举还没选的数字 num（即 mask 中为 0 的位），若 num 与位置 cnt+1 满足整除条件，则可以从 dp[mask] 转移到 dp[mask | (1< 并累加。

第四步，初始化与答案。dp[0] = 1（空集算一种起点）。最终答案是 dp[(1<（所有位都置 1，即全选完）。

参考代码

class Solution {
    public int countArrangement(int n) {
        int full = 1 << n;                    // 状态总数 2^n
        int[] dp = new int[full];
        dp[0] = 1;                            // 空集：一种起点

        for (int mask = 0; mask < full; mask++) {
            int cnt = Integer.bitCount(mask);  // 已填的位置数 = 已选数字数
            if (cnt >= n) continue;            // 填满了不用再扩
            int pos = cnt + 1;                 // 下一个要填的位置（1-indexed）
            for (int num = 1; num <= n; num++) {
                int bit = 1 << (num - 1);
                if ((mask & bit) != 0) continue;          // num 已选过，跳过
                // 整除条件：num 被 pos 整除，或 pos 被 num 整除
                if (num % pos == 0 || pos % num == 0) {
                    dp[mask | bit] += dp[mask];           // 转移并累加
                }
            }
        }
        return dp[full - 1];                   // 全选完的排列数
    }
}

复杂度

O(n·2ⁿ) 时间（遍历 2ⁿ 个状态，每状态最多试 n 个数字），O(2ⁿ) 空间。把 n! 的暴力压到了可承受范围，是状压 DP 的经典范例。

为什么用 (1 << (num-1))：Java 里 1 << k 的 1 是 int，当 k ≥ 31 会溢出（本题 n≤15 安全）。但凡 n 可能接近 30，就要用 1L << k 转 long 或确认范围，见 23.7 节坑三。

巩固练习（先自己想 15 分钟，卡住再看括号里的提示）

  • 划分为 k 个相等的子集（力扣 698，中等）——同「用 bitmask 表示已分配数字」；差异在目标是分 k 个等和桶（提示：dfs + 记忆化，用 mask 记已用数字，尝试把当前数塞进某个未满的桶，可配 visit 数组剪枝）。
  • 火柴拼正方形（力扣 473，中等）——状压/回溯孪生；差异在4 个桶（边长 = 总和/4）（提示：与 698 同理，把 4 条边当 4 个桶，排序后从大到小放可大幅剪枝）。
  • 大礼包（力扣 638，中等）——状压 / 记忆化；差异在needs 向量作为状态（提示：用「当前还差多少需求」的数组当状态做记忆化搜索，优先用划算的大礼包）。

23.6记忆化搜索：自顶向下的 DP（中等，力扣 329）

中等 核心：递归 + 缓存数组

题意：给一个 m×n 整数矩阵，找一条严格递增的路径（每步只能走向上下左右相邻且值更大的格子），求这样的路径的最大长度。例：[[9,9,4],[6,6,8],[2,1,1]] → 最长递增路径 1→2→6→9 或 1→2→6→8，长度 4。

思路推导

第一步，天然适合「从某点出发」。把问题看作：从每个格子出发，能走出的最长递增路径是多少？定义 dfs(x, y) = 从 (x,y) 出发的最长递增路径长度。

第二步，自顶向下递归。从 (x,y) 出发，枚举四个邻居，只对值更大的邻居递归 dfs(nx, ny)，取其中最大的加 1。但这样裸递归会指数爆炸——同一格子被反复作为起点计算。

第三步，加缓存 = 记忆化搜索。用一个 memo[x][y] 记录「从 (x,y) 出发已算出的最长路径」。每次进 dfs 先看缓存有没有，有就直接返回；算完存回。这就把重复子问题砍掉，等价于 DP，但代码是顺着人类直觉写的递归，比硬凑填表顺序舒服得多。

第四步，自顶向下 vs 自底向上。两者数学上完全等价——记忆化搜索就是「自动按依赖顺序填的 DP」。选择标准：当状态难以用循环优雅地枚举（比如本题起点任意、依赖图不规则），用记忆化；当填表顺序清晰（如区间、线性），用自底向上迭代更省栈空间。

参考代码

class Solution {
    int[][] memo;                    // 缓存：从 (x,y) 出发的最长递增路径
    int[][] matrix;
    int m, n;
    int[][] dirs = {{-1,0},{0,1},{1,0},{0,-1}};

    public int longestIncreasingPath(int[][] matrix) {
        this.matrix = matrix;
        m = matrix.length; n = matrix[0].length;
        memo = new int[m][n];        // 初始 0 表示未算（长度至少 1，不会冲突）
        int ans = 0;
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                ans = Math.max(ans, dfs(i, j));   // 每个点都当一次起点
        return ans;
    }

    private int dfs(int x, int y) {
        if (memo[x][y] != 0) return memo[x][y];    // 算过直接返回（缓存命中）
        int best = 1;                               // 至少包含自己
        for (int[] d : dirs) {
            int nx = x + d[0], ny = y + d[1];
            if (nx >= 0 && nx < m && ny >= 0 && ny < n
                && matrix[nx][ny] > matrix[x][y]) { // 只走严格更大的邻居
                best = Math.max(best, 1 + dfs(nx, ny));
            }
        }
        memo[x][y] = best;                          // 存回缓存
        return best;
    }
}

复杂度

O(m·n) 时间（每个格子最多真正计算一次），O(m·n) 空间（缓存 + 递归栈）。自顶向下写法在这里比硬写迭代 DP 清晰太多。

用 0 当「未计算」标记是安全的：因为路径长度最少是 1（自己），任何真实答案都 ≥1，所以缓存初值 0 能干净表示「还没算」。若题目允许答案可能为 0，则需另用 boolean[][] visited 或把缓存初值设成 -1。

巩固练习（先自己想 15 分钟，卡住再看括号里的提示）

  • 目标和（力扣 494，中等）——记忆化/背包；差异在给数前面加 + 或 - 凑目标和（提示：用 memo[index][sum] 缓存「从第 index 个数起、当前累加和为 sum 的方案数」，或转 0-1 背包）。
  • 出界的路径数（力扣 576，中等）——带步数记忆化；差异在限制走 k 步且统计走出边界的路径（提示：dp[r][c][step] 记忆化，step 递减到 0 时若越界则计 1）。
  • 翻转游戏 II（力扣 294，中等）——记忆化胜负；差异在用 bitmask 记剩余可翻位置、缓存胜负（提示：memo[mask] 表示当前局面先手能否赢，枚举每次翻转后递归对手）。

23.7本专题常见坑

  • 坑一：区间 DP 遍历方向写反。区间 DP 的转移依赖「更短区间」（dp[i+1][j-1] 等左下/下方格）。若 i 从 0 往 n 走，算 dp[i][j] 时 dp[i+1][...] 还没算，全是 0，结果全错。记住：i 从后往前、j 从 i+1 往后。
  • 坑二：树形 DP 忘返回数组 / 漏算一维。打家劫舍 III 必须返回「偷/不偷」两个值。若只返回一个最大值，父节点无法判断「孩子偷了没」，会算出「父子同偷」的非法解。务必返回 int[2] 并两维都更新。
  • 坑三：状压 1 << n 溢出 int。当 n 接近 31，1 << n 或 1 << (num-1) 在 int 下会溢出变负。n 偏大时用 1L << k 并配合 long 状态，或事先确认 n 范围。
  • 坑四：记忆化忘初始化缓存 / 标记未算。若缓存初值和「合法答案」冲突（如答案可能为 0），会误判命中缓存。用 boolean[][] 显式标记，或初值取不可能出现的数（如 -1）。
  • 坑五：混淆子串与子序列。最长回文子串（连续，中心扩展）和最长回文子序列（不连续，区间 DP）是不同题，套错方法直接 WA。动手前先确认「要不要连续」。

23.8自测题

Q1.【动手题】对区间 DP「最长回文子序列」，写出 dp 数组的初始化（哪些格子已知）和双重循环的大致顺序，并解释为什么 i 必须从后往前。

初始化 dp[i][i]=1（单字符）。循环：for i=n-1..0; for j=i+1..n-1。i 从后往前是因为 dp[i][j] 依赖 dp[i+1][j-1] 与 dp[i+1][j]（左下方格），必须保证这些更短区间先算完，倒序才能保证依赖已填。

Q2. 打家劫舍 III 为什么返回 int[2] 而不是一个整数？如果只返回一个值会怎样？

因为父节点做决策需要知道「孩子偷了 / 没偷」各自的最大收益：偷父则孩子必不偷（取孩子的[0]），不偷父则孩子取 max。若只返回一个总最大值，父节点无法区分孩子是否偷过，可能算出父子同偷的非法解。返回两值才能正确组合。

Q3. 状态压缩 DP「优美的排列」，为什么 n 不超过 15 就能做、而直接暴力不行？

暴力枚举排列是 n! 种，n=15 时约 1.3×10¹² 无法承受。但「已选数字集合」只有 2ⁿ 种（2¹⁵=32768），用 bitmask 表示集合后，状态数从阶乘级压到指数级（但仍小），再用 O(n·2ⁿ) 转移即可在时间内算完。
