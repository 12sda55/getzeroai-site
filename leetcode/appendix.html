A.2Java 刷题 API 速查

数组与排序

int[] a = new int[n];                 // 全零数组
int[] b = {3, 1, 2};
Arrays.sort(b);                       // 升序 O(n log n)
// 降序要给比较器（只能对 Integer[] 或 List 用）
Integer[] c = {3, 1, 2};
Arrays.sort(c, (x, y) -> y - x);
Arrays.fill(a, -1);                   // 整个数组填 -1（DP 初始化常用）
int[] d = Arrays.copyOfRange(b, 1, 3);// 截取 [1,3)

字符串

String s = "abc";
s.length();  s.charAt(0);             // 长度 / 第 i 个字符
char[] cs = s.toCharArray();          // 转字符数组（要修改时）
String t = new String(cs);
StringBuilder sb = new StringBuilder();
sb.append('x');  sb.reverse();  sb.toString();  // 拼接/反转，O(1) 均摊
s.substring(1, 3);                    // 子串 [1,3)
String[] parts = "a,b".split(",");    // 分割
s.trim();  s.equals(t);  s.compareTo(t);  // 去空白 / 比较（别用 ==）
Character.isLetterOrDigit(ch);  Character.toLowerCase(ch);

集合三件套

Map<String, Integer> map = new HashMap<>();
map.put("a", 1);  map.get("a");
map.getOrDefault("b", 0);             // 计数场景标配：getOrDefault(key, 0) + 1
map.containsKey("a");  map.remove("a");
for (var e : map.entrySet()) e.getKey() + "=" + e.getValue();
map.keySet();  map.values();

Set<Integer> set = new HashSet<>();
set.add(1);  set.contains(1);  set.remove(1);

// 计数小技巧：merge 一行完成「存在则加，不存在则放」
map.merge(ch, 1, Integer::sum);

栈、队列、堆（Deque / Queue / PriorityQueue）

// 栈：用 Deque，别用遗留的 Stack 类
Deque<Integer> stack = new ArrayDeque<>();
stack.push(1);   stack.pop();   stack.peek();      // 压 / 弹 / 看顶

// 队列：Queue 接口
Queue<Integer> queue = new ArrayDeque<>();
queue.offer(1);  queue.poll();  queue.peek();      // 入 / 出 / 看头

// 双端队列（滑窗、单调队列用）
Deque<Integer> dq = new ArrayDeque<>();
dq.offerLast(1);  dq.pollLast();  dq.pollFirst();  dq.peekFirst();

// 堆：小顶堆默认；大顶堆给反向比较器
PriorityQueue<Integer> minHeap = new PriorityQueue<>();
PriorityQueue<Integer> maxHeap = new PriorityQueue<>((a, b) -> b - a);
minHeap.offer(1);  minHeap.poll();  minHeap.peek();
两个高频坑： ① (a, b) -> b - a 这种相减写法在「极大值减极小值」时会整型溢出， 稳妥写法是 Integer.compare(a, b)（升序）或 Integer.compare(b, a)（降序）； ② int[] 数组不能做 HashMap 的 key（比较的是引用不是内容）， 需要时先包成 String 或 List<Integer>。

A.490 天刷题路线（Hot 100）

按本站专题排的 90 天计划（覆盖前 12 个基础专题；13~24 号进阶专题学完后按面试方向自选加练），每天 1 题、每周 6 题 + 1 天复盘，共约 75 题有效量。 「有效」的定义见总览 0.3 五步法。题目都来自力扣 Hot 100，标注了对应专题页：

A.5卡住了怎么办：看题解的正确姿势

卡住是常态，看题解不可耻。可耻的是看完就过。按下面这个阶梯来，把每次「看题解」的价值榨干：

阶梯动作什么时候升级到下一阶
1只看本站该题的思路推导部分，到「想到这个解法」为止，不看代码，合上自己写15 分钟还是写不出
2看代码的前几行（状态定义 / 变量命名），推断后续，再自己写完10 分钟还是写不出
3看完整参考代码，逐行理解后合上，从头默写默写通过所有用例
4三天后脱稿重写（五步法第 5 步）；写不出回到阶梯 3一次通过 → 这题真正属于你了
标记你的「真不会」名单。凡是走到过阶梯 3 的题，记下来。 它们是你最宝贵的复习材料——面试前只复习这个名单，效率远高于盲目二刷。

Q. 阶梯 3 的「默写」和死记硬背有什么区别？

检验方法是：默写时你能说出每一行在整条思路里的位置（「这行是在做滑动窗口的收缩」）。 如果只是手指记忆，三天后重写必挂，那就回到思路推导重新理解。宁可慢，不要背。

用这份附录验收你的备考：复杂度表能对着数据范围口算出「这题目标复杂度是多少、用哪个技巧」； 模板索引里 12 个模板全部脱稿默写通过；90 天路线你能说出自己当前在第几周、落后多少。 三条都做到，Hot 100 的核心你就拿下了。
